# SVG动画可选分支

仅在教师明确选择制作或修改动画时读取本文件和[SVG定稿](../prompts/animation.txt)。规范已存在、用户要整套、教师确认六项或仅请先建议，都不自动启动分支。

## 分镜确认

确认主题、观察目标、专业依据和使用位置，已有信息直接沿用，不再要求机械填写O部分。按定稿形成教学简表和可执行分镜，说明关键状态、停驻点、控制、假设与专业疑点，交教师审阅。分镜未确认不制作动画；已有明确分镜且教师要求照做时承接既有授权。

默认是核心图形为SVG的离线单文件HTML，不是静态SVG图片。遵循定稿的尺寸、单屏、知识关系与控制要求，“示意”不豁免错误因果。

## 第一版与实际测试

制作带版本号的文件，在具备条件时实际打开，按定稿T检查主图、关键状态、专业关系、视口、控制和离线运行。能确定的错误直接修正，未测试项如实标明，截图须来自实际运行。

交付第一版、打开方法、需教师试用的关键场景、已测及待核项，状态记“待教师试用”，等待反馈。模型自检不代表用户接受；没有回复不得自动宣告验收或挂入最终课件。

## 多轮修订

根据反馈定位版本、阶段和操作，例如暂停仍运动、变化看不清、方向错、标签过小。明确修改直接执行，只有必要定位缺失才追问。

另存新版本，修正并复测受到影响的状态、控制和知识关系，保留前版便于比较。每轮展示实际修改与复测，交教师再次试用。明确接受后才记教师已确认；用户接受也不把未测项变成已通过，关键未解错误仍需说明。

同一阻碍两轮针对性修复仍失败时说明并请教师决定调整表达或暂停，不无休止自循环。新反馈可以启动新修订轮；不存在“测两次自动通过”。

## 与常规资源交付的关系

四类常规资源先建立可实际使用的静态教学安排。动画未选、分镜待确认或试用中不构成常规流程必备条件，不插入失效占位链接或声称动画已交付。

动画被教师接受后，在已有接入授权或教师明确要求下，更新PPT入口、备注和打开说明，检查实际目标环境，保留静态讲解方式。浏览器运行与PPT内嵌播放分别验证，不假定SVG/HTML可以原生内嵌播放。

主流程改动影响已有动画时标记需复核，未授权不重写源动画；有关键错误未解决的动画不继续推荐用于授课。
