# 工单与板书规范入口
v0.3.2已将两类成果分别纳入专门PROMPT：
- 工单制作前完整读取[工单提示词](../prompts/worksheet.txt)。
- 板书制作前完整读取[板书提示词](../prompts/board-plan.txt)。

两者处于不同阶段：教案自检通过→工单及红字答案自检通过→PPT自检通过→板书自检→独立审查。
工单每学时一页，答案版保留原题面并在作答区用红字填写，不再采用单独答案列表。
板书交付一个可编辑DOCX，按课次和课堂时序汇总所有阶段的实际有效板面、最终总览与书写说明。主体必须实际排出板面内容，不能只写文字建议，也不把整页PNG/SVG贴入Word。工单只交付DOCX，不附PDF。
具体交接见[执行规则](workflow.md)，最终核对见[独立审查](independent-review.md)。本页仅保留兼容入口，不重复维护另一套规则。
