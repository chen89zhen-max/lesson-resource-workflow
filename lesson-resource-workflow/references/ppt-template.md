# 中职通用教学模板

## 文件与用途

- `../templates/vocational_teaching.pptx`：六页可编辑版式起稿。占位内容供制作时替换，不是完整课件，不是16套PowerPoint母版。
- `../examples/magnetism-six-slides.pptx`：《磁现象的探究》六页精修示例，展示实际图文效果。已进行屏幕渲染与独立美学审查，未声称完成真实教室投影验证。
- `../scripts/init_deck.py`：只复制通用起稿，不自动生成课程内容。
- `../scripts/check_deck.py`：检查文件并渲染，供主代理和独立审查者实际看图。

适用于中职公共基础课、专业理论课及实践课中的讲解页面。保留暖白、深青、赭橙的基础关系，按课程内容调整。六类页型可重复、增删或扩展，不能把每套课件固定为六页；无需为了数量比例插入不必要版式。教师明确指定的视觉要求优先。

## 复用步骤

1. 实际打开通用起稿及磁学示例的页面预览或真实幻灯片视图，读取已定稿教案与工单。不能只读文件名、文字或颜色参数；已有与原文件一致的预览可复用。
2. 先按教学内容选对应页型，制作代表页并与起稿/示例对应页并列看图：核对构图比例、主视觉、信息层级、对齐留白、练习反馈同位关系。通过后才复制扩展，简记参考页→成品页及必要改动。用宿主PPTX编辑工具打开并另存起稿，也可运行 `python <技能目录>/scripts/init_deck.py <输出.pptx>`。以宿主实际支持的方式复制或增删页，禁止将整个起稿截图后冒充可编辑课件。
3. 替换所有 `slot:*` 内容对象、`meta:*` 课程元信息及教师备注。图示框 `slot:visual`（或带序号的同类对象）与对应 `_hint` 提示文字应一并删除，再放实际图示。名称可在选择窗格或PPTX对象API中读取。
4. 图片按用途等比适配。精确图示保留端点和标签；主题图可裁切。采用原生对象重绘时按依据核对连接、条件、方向与符号。
5. 不将磁学示例中的磁铁、指南针、N/S、题目、答案或备注带入其他课程。通用起稿不含这些学科素材。
6. 写入本课讲解、参考答案、典型错误及实际来源；问题页不提前展示答案。更新页码，删除无用页面。
7. 检查、渲染并逐页看图，同时对照实际参考页面，分别验收有效页数、教学内容和美学保真。字体边界自动检查不能评价构图优劣；修改后复核受影响页面，最后独立审查。

宿主有自己的PPTX生成或模板导入能力时优先使用。不能导入原生页面但能生成可编辑对象时，可按以下设计关系重建并如实说明；不强依赖某一家付费技能或私有库。不能生成或查看实际文件时，报告能力限制，不把文字方案称为已生成课件。

## 六类版式

所有位置以1280×720逻辑画布描述，用于理解比例，不是必须使用的编程单位。实际画幅为13⅓×7.5英寸。逻辑像素转PowerPoint磅时乘0.75；不要把32像素误称为32磅。

| 页型 | 主要设计关系 | 内容对象 |
| --- | --- | --- |
| 封面 | 左侧大标题和核心问题，右侧主题视觉；示例可采用有留白的全幅背景 | title、subtitle、focus、visual |
| 大图讲解 | 图区约占左侧六成，右侧两组条件与结论；底部整页重要提醒 | visual、label_1/2、rule_1/2、relation、takeaway |
| 状态比较 | 两行同尺度对象，位置对齐；突出状态变化或关键差异 | label_1/2、result_1/2、visual_1/2、difference_1/2 |
| 练习 | 左图与右侧作答区接近等宽，题干完整、答案隐藏 | visual、question_1/2/3、response_1/2/3 |
| 反馈 | 保留练习图位置；每组先看大答案，再读依据 | visual、item_1/2/3、answer_1/2/3、reason_1/2/3 |
| 小结 | 左侧归纳，右侧离堂问题与直接相关的图片；题设条件完整 | label_1/2/3、detail_1/2/3、exit_question、exit_visual |

表中的对象名均带 `slot:` 前缀；示例文件是已完成课件，不承诺有相同的命名接口。答题数量、结论字数超出容量时拆页或调整布局，不缩小正文来迁就固定框。表格、公式推导等必要页型可在同一设计体系下扩展。

## 投影与美学要求

- 背景 `#F8F7F2`，深色文字 `#172D36`，次级文字 `#52636A`，强调色 `#17667A`、`#B34E28`，浅底 `#EBF0ED`。避免用过淡线条表达关键关系。
- 统一中文无衬线字体，首选微软雅黑；替代字体须实际检查换行。主要标题约36磅，正文、题干、依据、重要概念和图中关键标签至少24磅；反馈答案约36磅。页码、课程标记和题序属于元信息，可小于24磅，不把重要教学文字伪装成元信息。
- 图片与问题须指向同一对象或提供理解所需证据。不要仅因“主题相关”就让装饰图占据关键教学位置。
- 练习与反馈维持图示坐标，判断结论比解释更醒目。比较对象尺度一致，受力箭头与磁感线箭头等不同符号需明确语义。
- 允许合理留白，允许无图片或纯矢量页面，不以“空白底版”“图片数量”“单一母版占比”判定美学优劣。但只保留同配色字号、所有页面退为统一纯文字卡片，不构成模板美学复用；应回到原页面检查主视觉和构图关系，不以“内容完整”豁免。
- 模型是人为描述不等于必须用虚线。线型按学科惯例、题意及教材选择，同一含义一致；磁学示例采用带箭头的细实线。
- 两张示例静物由AI生成，用途与限制写在备注。主题插画不能冒充真实实验，不能用未经核验的生成图承担精确专业判断。

## 自动检查与实际渲染

Python依赖见 `../scripts/requirements.txt`。渲染额外需要LibreOffice，以及PyMuPDF或Poppler二选一。使用现有环境；缺依赖时说明需要哪些工具，不自动替用户更改系统环境。

```text
python <技能目录>/scripts/check_deck.py <课件.pptx> --render-dir <工作目录/_render_check>
```

程序未在PATH时可传入 `--soffice <程序路径>`、`--pdftoppm <程序路径>`；这些是调用者本机配置，不写死在公共技能中。

- 退出码0：自动结构检查与全量渲染完成，报告里的 `visual_review` 仍为待人工看图。
- 退出码1：存在错误，修复后复核。
- 退出码2：缺渲染能力，或显式执行了 `--structural-only`；不能宣称视觉通过。
- `--template` 只用于通用起稿本身的维护检查，允许占位文字。不能对课堂成品用此开关绕过检查。

报告、逐页PNG、联版图和中间PDF均在指定的工作目录，非最终成果附件。脚本不能判断知识正确性、图文关联或真实教室效果，也不能证明所有继承字号、复杂组内变换均正确；出现相应警告时人工核验。学校名称和其他身份信息不能靠通用正则穷尽，公共发布前还要独立隐私审查。

没有这些依赖时，可用宿主等效工具检查字号、页面边界、备注与占位残留，并渲染实际页面。记录采用了什么工具、看了哪些页、哪些项目未完成；不能谎称本脚本退出0。已有与最终版本一致的实际预览可复用。

## 迁移说明

v0.5.1取消旧 `school_template.pptx`、`build_deck.py` / `SlideDeckBuilder` 与16版式索引协议。它们与旧学校母版绑定，不能对新起稿直接调用。新的通用起稿采用可编辑页面与命名内容对象，按本规范使用宿主PPTX工具完成填充。

## 0.5.4内容验收
必须同时执行[详案与课件内容美学验收](content-quality.md)。格式、字号、渲染通过不代表教学内容完整；教案详案与思政落实、课件有效页数、内容充分性和模板美学分别验收。
