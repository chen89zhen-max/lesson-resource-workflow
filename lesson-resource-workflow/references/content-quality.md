# 详案与课件内容美学验收

## 教案
保留六部分40行及原有事实边界。课前与课中五列采用[2,2,2,3,1]，对应约1.37、3.24、4.00、4.63、3.88厘米；学生活动列不得缩为1.75厘米。课后按原规定。完整内容自然跨页，不设总页数上限。

核心环节必须能据以实施：具体学科问题及答案要点、教师如何讲解/示范、学生如何独立参与并形成产出、教师依据什么判断、典型错误出现后怎样反馈与再检查。教师和学生两列横向对应，不能用“观察、讨论、互查、修改”等词代替对象与过程。不要求逐字讲稿，不凭字数评价质量；必要内容不能转嫁给工单、课件或备注。不预写授课成效，不复制参考教案的未核实学情数据与数字工具能力。

教案按M3检查明确育人价值、主动挖掘真实专业联系、筛选自然融入路径与核验。制作记录简记具体价值、候选联系、取舍及路径。专业事实正确或有判断题不足以证明育人充分；教师示范、真实技术史、劳动榜样、应用比较、讨论或实践均可自然融入，不机械每课末尾附加两分钟。学生应有体会、反思或行动机会，不凭一次答对评思想；有适切点漏落实需修正，不数标签。

## 课件
每次连堂课至少12页有效教学内容，按实际知识与活动增加，不固定总页数。封面、目录、纯过渡、结束、空白或重复凑数页不计入。含有具体归纳及学习检查的小结可以计入。六类模板是版式库，不能当作六页容量。

先按教案编逐页教学计划，实际查看原起稿与磁学示例页面，再选择适配构图。代表页与参考页并列审核通过后才复制扩展。每页须有具体教学作用、真实可见的内容和相应学生任务或学习证据；不得拆碎一句话凑页。教师明确改变交付范围时记录原话与例外原因，不能由模型自行豁免。

保存 `<课件名>.teaching-pages.json`，覆盖全部实际页面，按当前演示顺序连续编号。例如：

```json
{"schema_version":1,"pages":[
  {"page":1,"role":"cover","purpose":"课题及本课任务","task_or_evidence":""},
  {"page":2,"role":"teaching","purpose":"识别图中电流与磁场的方向","task_or_evidence":"每人在工单图上标出两种方向并说明依据"}
]}
```

role只用`teaching/cover/agenda/transition/closing`。只有teaching计入；其purpose和task_or_evidence不可空。示例仅演示JSON格式，不是达标课件。可显式指定 `check_deck.py 课件.pptx --teaching-manifest 清单.json`，省略时自动寻找同名清单。结构检查也检查清单；`--template`仅用于模板和版式示例维护，不可用于课堂成品规避页数检查。

程序核对实际页数、清单连续唯一、有效页数量、空页和完全重复内容，不以总页数替代有效页数。程序无法证明清单所写教学作用真实成立，报告中的teaching_review始终为待人工核验。人工逐页查看成品、对照目标和任务，剔除伪教学页并更新清单后重跑；课件内容修改后同步清单和教案映射。

## 美学保真
用实际页面对照构图与图文比例、主视觉、信息层级、对齐留白、练习与反馈同位关系。颜色和字号一致不能自证复用；扩页不能变成统一纯文字卡片。允许适合任务的纯文字页和必要新页型，不设每页必须有图或版式比例。记录代表页对应与适配理由，最终逐页检查，不能只看抽样美图。

## 分开给出结论
1. 文件结构与渲染：实际运行范围、失败项及修复。
2. 教案可实施性：逐个核心环节的具体证据与遗漏。
3. 课件教学完整性：总页数、有效页数、排除页码、逐页作用、难点和反馈是否展开。
4. 模板美学保真：实际参考页与成品构图对照、退化或适配说明；与数量和内容分开验收。
5. 真实课堂效果：未实测就写未实测，不能用上述各项替代。

独立审查必须读取实际文件；已有“自检通过”与页数清单不能替代审查。发现核心环节仍为口号或有效页不足、或只有配色字号一致而构图明显退化时，整套不能标记全部验收通过；分别指出内容、数量或美学哪一项未通过。
